☁ Cloud sync setup

This connects your schedule to Google Sheets so it syncs across every device and browser. Follow the steps below, then paste your Script URL here.

Step 1 — Go to sheets.google.com and create a new blank spreadsheet. Name it "Dance Schedule".
Step 2 — Click Extensions → Apps Script.
Step 3 — Delete everything in the editor and paste in the contents of Code.gs (the other file you downloaded).
Step 4 — Click Deploy → New deployment. Type: Web app. Set "Who has access" to Anyone. Click Deploy.
Step 5 — Copy the Web App URL and paste it below.
This URL is saved in this browser so you only need to do this once per device.
